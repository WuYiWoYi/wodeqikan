## 阶段 1：大地图基础系统

**状态：** 完成（Milestone 1）
**目标：** 玩家能在大地图上移动、控制时间、与地点进行基础交互。

Milestone 1 实际交付：

- 主菜单：新游戏 / 继续 / 读取列表 / 设置占位 / 退出。
- 3000×2000 大地图、玩家部队、2 支 NPC 部队、4 个地点。
- 点击移动、边界限制、摄像机跟随/平移/缩放。
- 暂停 / 1x / 2x 时间控制。
- 地点交互面板（主动点击打开、到达停止、暂停、离开后仍暂停；阶段 6 修订为不再靠近自动打开）。
- JSON 存档、Continue、Load Game、版本检查与原子写入。

### 任务

1. 大地图场景背景与地图边界（`WorldMapManager.world_bounds`）。
2. 玩家部队数据与旗帜图标。
3. 点击地面设置目标，部队按世界 tick 移动。
4. 图标表现：读取数据并平滑插值，不写回数据。
5. 时间控制 UI：暂停、正常、二倍速，绑定 `TimeManager`。
6. 地点数据（村庄/城镇/城堡）与地图标记。
7. 到达地点后打开左侧交互面板；初期只有“离开”。
8. 面板打开时压入暂停原因，关闭时移除。

### 验收标准

- 玩家部队能在地图边界内移动，速度受时间倍率影响。
- 暂停时大地图世界完全静止，UI 动画仍运行。
- 到达地点弹出面板；离开后保持暂停，下一次操作恢复。

## 完成定义（DoD）

一个任务算完成，必须同时满足：

1. 代码可运行，无解析错误与新增运行时报错。
2. 有对应验收方式（冒烟测试、手动步骤或单元测试）。
3. 测试范围与改动影响匹配（L1–L4），并记录未验证的关联风险。
4. 相关文档、`Current_Status.md` 已更新。
5. 新增接口/字段已写入对应系统文档。
6. 未引入新的全局单例或跨层直接写数据。
